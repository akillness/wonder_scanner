# 📄 PRD — Wonder Scanner

| 항목 | 내용 |
|---|---|
| 제품 | Wonder Scanner — 카메라로 일상 사물의 "진짜 모습(원더)"을 발견·수집·기록하는 AR 도감 게임 |
| 버전 | v5 (2026-09-23) · 라이브 https://wonderscanner.vercel.app |
| 플랫폼 | 모바일 웹(iOS Safari, Android Chrome) 우선 · 데스크톱은 사진 업로드 폴백 |
| 원칙 | ① 서버 없이도 완전한 게임 ② 카메라 프레임은 기기 밖으로 나가지 않음 ③ 모든 수치는 한 파일에서 조정 ④ 세계관·저장소·클라우드는 교체 가능한 어댑터 |

## 1. 비전과 문제

**비전.** "세상은 원더로 가득한데 사람들은 그냥 컵이라 부른다." 스마트폰 카메라를 마법 렌즈로 바꿔, 평범한 하루의 물건들이 수집·기록·공유할 가치가 있는 존재로 보이게 한다.

| 사용자 문제 (JTBD) | 오늘의 해법 | 우리의 답 |
|---|---|---|
| 지루한 공간에서 잠깐 즐길 "가벼운 놀이"가 필요하다 | 릴스·모바일 게임 | 카메라를 들면 3초 안에 시작되는 스캔 루프 |
| 찍은 사진이 갤러리에 묻힌다 | 사진 앱 | 사진이 성장하는 **추억**이 되고, 회상·다듬기가 보상으로 이어진다 |
| 수집 게임은 지갑을 열게 만든다 | 가챠 | 현실 세계가 곧 드롭 테이블 — 돈 대신 관찰력이 희귀도를 결정 |
| 혼자 하는 수집은 금방 식는다 | SNS | 선물 코드(서버 없음) → 광장(클라우드) 단계적 소셜 |

## 2. 페르소나

| 페르소나 | 상황 | 성공 지표 |
|---|---|---|
| 🎒 **행사 참가자 (1회성)** | QR로 진입, 5분 체험 | 첫 발견까지 90초 이내, 카드 1장 공유 |
| ☕ **일상 탐험가 (리텐션)** | 하루 1~3회, 출퇴근·점심 | 7일 연속 출석, 챕터 1개 완성 |
| 📸 **기록가 (깊이)** | 앨범·캡션·필터를 정성껏 | 추억 ⭐ 단계 3개 이상, 콜라주 공유 |
| 🏆 **컬렉터 (경쟁)** | 80종 완성, 광장 순위 | 보물상자 6개, 광장 상위 10 |

## 3. 기능 요구사항

### 3.1 코어 루프

| ID | 기능 | 요구사항 | 상태 |
|---|---|---|---|
| F-01 | 온디바이스 인식 | COCO-SSD 80종, 신뢰도 ≥0.5, 신뢰도 0.7 + 화면 점유 0.3 가중 타깃 선택 | ✅ |
| F-02 | 공명 게이지 | 신뢰도 비례 충전(기준 2.2초), 놓치면 감쇠, 부스트·사건 배율 | ✅ |
| F-03 | 타이밍 포획 | 줄어드는 링, 목표 0.30, PERFECT ≤0.045 / GREAT ≤0.10 / GOOD ≤0.17 / MISS(도망) / 3사이클 AUTO | ✅ |
| F-04 | 발견 연출 | 서스펜스(영웅+) → 플립 → 스탬프 → 파티클 → **스크래치**로 이름·정체 공개 | ✅ |
| F-05 | 도감 | 80칸 실루엣, 챕터 6, 진행 링, "N개만 더", 깊이 노트(3회/10회), 마스터 프레임 | ✅ |

## 5. 지표 (North Star: 주간 활성 탐험가의 "추억 진화 수")

| 단계 | 지표 | 목표 |
|---|---|---|
| 활성화 | 첫 발견까지 시간 | < 90초 |
| 참여 | 세션당 포획 수 / PERFECT 비율 | 3+ / 25% |
| 리텐션 | D1 / D7 출석 | 40% / 20% |
| 깊이 | 캡션 있는 추억 비율, ⭐ 단계 추억 수 | 30% / 인당 2 |
| 소셜 | 카드·클립·콜라주 공유, 선물 코드 교환 | 인당 1/주 |

## 6. 세계관 확장 (Extensible World)

| 계층 | 파일 | 확장 방법 |
|---|---|---|
| 세계 레지스트리 | `src/data/worlds/index.js` | `{ id, name, tagline, wonders, chapters, guide, unlockRule }` 등록 |
| 원더 사전 | `src/data/wonders.js` | 같은 80 라벨에 다른 이름·설정·희귀도 → "야상곡 세계" 등 |
| 안내자 | `src/game/narrative.js` | 대사 세트 교체 (루페 외 NPC) |
| 사건 | `src/game/companion.js` `EVENTS` | 항목 추가만으로 새 사건 |
| 경제 | `src/game/economy.js` | 상점·마일스톤·프레임 항목 |
